### **Bank Credit & Debit Analysis | Team Project**

**Tools:** Power BI, Power Query, DAX, Microsoft Excel, MySQL

* Collaborated as part of a **7-member team** to develop an interactive Bank Credit & Debit Analysis dashboard for analyzing banking transaction data.
* Performed **data cleaning, transformation, and preparation** using Power Query and Excel to ensure accurate and analysis-ready data.
* Analyzed **credit and debit transactions, monthly transaction trends, branch performance, transaction methods, and account activity**.
* Created **KPIs, calculated measures, charts, and interactive slicers** to monitor key banking metrics and identify transaction patterns.
* Analyzed **high-value and suspicious transactions** to support risk monitoring and improve visibility into potentially unusual transaction activity.
* Developed dashboards with **dynamic visualizations and filters** to enable users to explore transaction performance by month, branch, transaction type, and risk status.
* Contributed to **dashboard design, data analysis, validation, and presentation** as part of the project team.
